# Требования receptionist-bot

Входная точка требований к сервису. Детальные требования появляются в каталоге `requirements` при принятии решений, которые их вводят. Пока все решения в состоянии `proposed`, действующих требований проекта нет; действуют требования ядра `platform`, доставленные пакетом правил.

## Ожидаемые требования

Появятся при принятии решений:

- календарь и запись — из [ADR-0003](decisions/ADR-0003-own-calendar-and-booking.md);
- политика отмен и штрафы — из [ADR-0004](decisions/ADR-0004-cancellation-policy-and-charges.md);
- аутентификация клиентов — из [ADR-0002](decisions/ADR-0002-telegram-client-authentication.md);
- персональные данные — из [ADR-0005](decisions/ADR-0005-personal-data.md).
