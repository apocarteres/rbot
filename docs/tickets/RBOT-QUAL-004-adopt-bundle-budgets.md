# Размер сборки клиента держит проверка

## Проблема

Превышение порога предупреждения бюджета сборку клиента не роняет и видно только в журнале: размер растёт незамеченным.

## Основание

Обязательство ядра `bundle-budgets`, требование `REQ-BUILD-014`, объявлено в версии ядра 5.0.0. Срок исполнения: 3 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. В angular.json у приложения объявлен бюджет начального пакета с maximumError (REQ-BUILD-014).
2. Пороги maximumWarning и minimumWarning сняты.

## Критерии приёмки

- Правило bundle-budgets в check замечаний не даёт.
- Сборка с заведомо превышенным порогом отказывает — проверено один раз при принятии.
