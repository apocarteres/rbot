# Куски прежней сборки клиента переживают раскат

## Проблема

Раскат стирает куски прежней сборки: вкладка, открытая до раската, не открывает раздел с отложенной загрузкой до перезагрузки.

## Основание

Обязательство ядра `static-archive`, требование `REQ-DEPLOYMENT-022`, объявлено в версии ядра 5.0.0. Срок исполнения: 3 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. Прежние куски лежат в архиве вне раздаваемого каталога; раскат и откат дополняют архив, ничего не стирая (REQ-DEPLOYMENT-022).
2. Веб-сервер ищет в архиве файл, которого нет в текущей сборке; index.html из архива не отдаётся (REQ-DEPLOYMENT-022).
3. Кусок хранится 7 дней с момента, как перестал раздаваться, либо срок проекта, записанный в его развёртывании (REQ-DEPLOYMENT-022).
4. Вечный кэш — только файлам с отпечатком, index.html — no-store, отказ — без вечного кэша (REQ-DEPLOYMENT-023).

## Критерии приёмки

- conventions static-check --url <стенд> --component <клиент> --previous <кусок прежней сборки> после раската проходит.
- conventions deployed по составляющей клиента проходит: архив в раздаваемый каталог не попал.
