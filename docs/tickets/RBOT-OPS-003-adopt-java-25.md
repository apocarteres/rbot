# Сборка потребителя идёт на Java 25, как и сборка ядра

## Проблема

Ядро собирается на Java 25 и публикует класс-файлы версии 69, а сборка проекта закреплена на Java 21: артефакты ядра такой сборкой не читаются, поэтому обновление версии ядра остановится на ошибке компиляции.

## Основание

Обязательство ядра `java-25`, требование `REQ-BUILD-004`, объявлено в версии ядра 1.0.0. Срок исполнения: 1 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. Версия Java в конфигурации менеджера окружения поднята до 25.
2. Цель компиляции Java-модулей поднята до 25 в манифестах сборки.
3. Образы и окружения, где идёт сборка и развёртывание, несут ту же версию Java.

## Критерии приёмки

- Наборы `check` и `verify` проходят на закреплённой Java 25.
- Версия в конфигурации менеджера окружения и цель компиляции в манифестах совпадают.
