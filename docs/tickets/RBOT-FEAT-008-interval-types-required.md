# Тип сессии у промежутка обязателен

## Проблема

Промежуток без отмеченных типов действовал для всех типов (RBOT-FEAT-004). Галочки по умолчанию сняты, и по виду окна нельзя понять, что промежуток открыт для всех типов, включая добавленные позже.

## Подтверждение

Решение владельца от 2026-10-01: если задан хотя бы один промежуток, требовать выбрать хотя бы один тип сессии; галочки по умолчанию сняты. Неделя по умолчанию — все дни выходные: новая база и рабочая среда уже без промежутков (на рабочей среде 0 промежутков на 2026-10-01).

## Последствия при сохранении текущего поведения

Новый тип сессии без ведома психолога получает время во всех промежутках без перечня.

## Требуется

1. Промежуток недели и особого дня без типов отвергается кодом `interval-types-required`; отказ показывается в окне.
2. Слоты типа строятся только из промежутков, где тип отмечен.
3. Переход базы заполняет пустые перечни уже заданных промежутков всеми существующими типами — расписание не меняется.

## Критерии приёмки

- `ScheduleIT`: промежуток без типов — 400 `interval-types-required`.
- `SlotCalendarTest`: промежуток даёт слоты только своим типам.
- Набор `rbot:006-interval-types-required` применяется на QA, прежние промежутки получают все типы.

## Ход работы

- 2026-10-01: `DayInterval.serves` — только по перечню; проверка в `ScheduleAdministration`; набор `rbot:006-interval-types-required` (`additive`, только данные). Подпись в окне — «Типы сессий — хотя бы один».
