# Ограничитель пояснительных комментариев сведён к нулю

## Проблема

Пояснительные комментарии, зафиксированные ограничителем при подключении правила, остаются в коде. Ограничитель не даёт им расти, но сам по себе их не убирает.

## Основание

Обязательство ядра `comment-ratchet-to-zero`, требование `REQ-CODE-COMMENTS-000`, объявлено в версии ядра 0.19.0. Срок исполнения: 6 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. Пояснение из комментария переносится в требование или решение, а код несёт ссылку на его идентификатор.
2. Комментарий, не несущий ничего кроме пересказа кода, удаляется.
3. Ограничитель опускается по мере работы с файлами, а не одним изменением по всему дереву.

## Критерии приёмки

- Раздел `comments` ограничителя равен нулю.
- Ни одно пояснение не потеряно: для каждого удалённого комментария есть либо документ, либо обоснование удаления в задаче.
