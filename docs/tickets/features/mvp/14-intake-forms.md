# Анкеты: шаблон, приём и раздел в кабинете

## Проблема

Новый клиент записывается через анкету. Сейчас кнопка «Записаться» на сайте психолога ведёт на Google Forms, и анкеты живут вне сервиса:

- психолог не видит их в кабинете рядом с клиентами и записями;
- из анкеты нельзя одним действием завести клиента и записать его на первичную консультацию;
- ответы хранятся у Google за пределами РФ.

## Подтверждение

Запрос владельца от 2026-09-30: в кабинете нужен раздел «Анкеты», как минимум для нового клиента, образец — действующая анкета на сайте.

Действующая анкета (Google Forms «Запись на консультацию психолога», просмотрена 2026-09-30):

| Вопрос | Вид | Обязателен |
|---|---|---|
| Ваше имя | строка | да |
| Ваш возраст | строка | да |
| Контактный телефон | строка | да |
| Адрес электронной почты | строка | да |
| Цель консультации, Ваш вопрос или проблема | текст | да |
| Какой формат работы Вас интересует? | один из: разовая консультация (диагностическая, получение рекомендаций) 1,5 часа; психотерапия очно; психотерапия онлайн | да |
| Согласие на обработку персональных данных | отметка | да |

Расхождения с [ADR-0005](../../../decisions/ADR-0005-personal-data.md), подтверждённые чтением формы:

1. Вопрос о цели консультации собирает сведения о состоянии здоровья (ст. 10 152-ФЗ), а текст согласия перечисляет только ФИО, телефон и e-mail. Возраст и цель консультации согласием не покрыты.
2. Ответы собираются в базу Google. Первичный сбор данных граждан РФ идёт не в базу на территории РФ (ст. 18 ч. 5).

## Последствия при сохранении текущего поведения

Анкеты вне сервиса. Психолог переносит их в кабинет вручную, а сбор сведений о здоровье через Google Forms с неполным согласием остаётся нарушением 152-ФЗ.

## Требуется

### Шаблон анкеты

1. Модуль `intake`: шаблон анкеты — неизменяемые версии вопросов. Виды вопросов: строка, текст, число, телефон, почта, один из вариантов, несколько вариантов. У вопроса есть текст, подсказка и признак обязательности.
2. Первая версия шаблона повторяет действующую анкету с сайта. Согласие — не вопрос шаблона, а согласие [MVP-03](03-clients-and-consent.md) со своей версией текста.
3. Кабинет: редактор шаблона с предпросмотром. Публикация создаёт новую версию, поступившие анкеты хранят версию, по которой заполнены.

### Приём анкеты

4. Открытая форма нового клиента на `bot.yanapaderina.com`: без входа, по действующей версии шаблона. Сначала согласие, потом вопросы. Та же форма позже открывается в Mini App (MVP-08) и заменяет Google Forms на кнопке «Записаться» сайта.
5. Точка приёма без входа открыта в `ApiAccess` явно и только она (`POST /api/intake/submissions`), шаблон для формы — `GET /api/intake/form`. Частота ограничена `platform-rate-limit` на адрес сети; защита от роботов — вопрос 3.
6. Ответы хранятся шифрованными (`SecretCipher`, ADR-0005), в журналы и метрики не попадают. Сроки хранения и удаление по запросу — как для карточки клиента (MVP-03).
7. После отправки клиент видит, что будет дальше (вопрос 4). Психологу — уведомление в колокольчике.

### Раздел «Анкеты» в кабинете

8. Список анкет: новые, в работе, обработанные, отклонённые; поиск по имени и контакту; число новых на главной.
9. Карточка анкеты: ответы по версии шаблона, дата, согласие и его версия.
10. Действия: «Завести клиента» — карточка `PROSPECT` из анкеты (MVP-03), связь анкеты с клиентом; «Записать на первичную» — переход к записи (MVP-05); «Отклонить» с причиной; удаление по запросу субъекта.

## Критерии приёмки

- Анкета, отправленная без согласия или без обязательного ответа, не сохраняется; отказ называет поле.
- Правка шаблона не меняет уже поступившие анкеты: они показываются по своей версии.
- Ответы в базе нечитаемы без ключа шифрования; имя, телефон и текст ответа отсутствуют в журналах (тест на захват журнала).
- Превышение частоты с одного адреса — `rate-limited`.
- Из анкеты заводится клиент `PROSPECT`, повторное нажатие не создаёт второго.
- Удаление по запросу стирает анкету и ответы; тест проверяет, что строк не осталось.
- На QA-стенде: анкета, заполненная на `qa.bot`, появляется в разделе «Анкеты» на `qa.admin`.
