# Каждый блок @defer объявляет @error

## Проблема

Блок @defer без @error после раската показывает на месте содержимого пустоту: отказ загрузки куска неизбежен, а молчание не отличить от решения.

## Основание

Обязательство ядра `defer-error`, требование `REQ-CLIENT-UPDATE-009`, объявлено в версии ядра 5.0.0. Срок исполнения: 3 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. У каждого блока @defer есть @error (REQ-CLIENT-UPDATE-009).
2. Содержимое @error несёт директиву apcrChunkFailure, чтобы отказ сразу сверял сборку (REQ-CLIENT-UPDATE-004).

## Критерии приёмки

- Правило defer-error в check замечаний не даёт.
