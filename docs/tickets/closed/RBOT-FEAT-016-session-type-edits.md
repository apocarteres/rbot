# Типы сессий: удаление, перерыв у типа, без «для нового клиента»

## Проблема

Заказчик на рабочей среде завёл дубли типов и не мог их удалить; признак «для нового клиента» ему не нужен; перерыв после сессии задавался одним на всю практику, а нужен свой у каждого типа; в окне промежутков не видно формата типа.

## Подтверждение

Правки заказчика от 2026-10-01, переданы владельцем:

- убрать опцию «только для новых»;
- удаление типа сессии; по умолчанию типов нет;
- под «Как увидит клиент» не показывать перерыв, нигде его не показывать; убрать перерыв из общих правил, задавать его у каждого типа;
- выводить формат рядом с типом там, где психолог задаёт промежутки дня.

## Последствия при сохранении текущего поведения

Дубли типов остаются в записи и в промежутках; перерыв одинаков для консультации и короткой сессии.

## Требуется

1. Удаление типа: тип пропадает из списков, записи и промежутков; промежуток, у которого не осталось типов, удаляется; прошлые записи сохраняют название типа.
2. Новая база — без типов: нетронутые сид-типы (выключены, цена 0, без записей) удаляются переходом.
3. Перерыв — поле типа «Перерыв после сессии, мин» (0–240); переход переносит в типы прежний общий перерыв; из «Правил записи», строки состояния и предпросмотра перерыв убран.
4. Признак «для нового клиента» убран из окна, списка и API.
5. В окне промежутков рядом с типом — формат («очно», «онлайн»).

## Критерии приёмки

- `ScheduleIT`: тип создаётся с перерывом, перерыв вне 0–240 — отказ; удаление — 204, повторное — 404; тип пропадает из списка, промежуток с ним одним удаляется; слоты считают перерыв типа.
- `SchemaMigrationIT`: в новой базе типов нет.
- Рабочая среда: прежний общий перерыв 15 мин — у каждого типа; нетронутый сид удалён, настроенные типы на месте.

## Ход работы

- 2026-10-01: переход `rbot:009-session-type-buffer` (`session_type.buffer_minutes`, `deleted_at`; удаление нетронутых сидов; чистка промежутков). Удаление мягкое: строка типа остаётся для истории записей, `Availability.everyType()` отдаёт и удалённые для названий. `PracticeSettings` без перерыва; `SlotCalendar.free` берёт перерыв типа; столбцы `practice_settings.buffer_minutes` и `session_type.first_visit` больше не читаются — снятие отдельным переходом `contract`.
- Кабинет: окно типа — поле перерыва, без «для нового клиента»; иконка удаления с подтверждением; после удаления неделя перечитывается. Окно промежутков — формат рядом с типом. Интеграционные тесты заводят свои типы.
