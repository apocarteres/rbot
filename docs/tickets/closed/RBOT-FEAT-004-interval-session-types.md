# Промежутки расписания для выбранных типов сессий

## Проблема

Промежуток рабочего дня действовал для всех типов сессий. Задать, например, «вечер — только онлайн» было нельзя.

## Подтверждение

Требование владельца от 2026-10-01: если у промежутка тип сессии не задан, промежуток действует для всех типов, если задан — только для заданных.

## Последствия при сохранении текущего поведения

Клиент получает слоты любого типа в любом промежутке, и психолог разводит типы вручную.

## Требуется

1. У промежутка недели и особого дня — перечень типов сессий, пустой перечень — все типы.
2. Слоты типа строятся только из промежутков, открытых для этого типа. Пересечение промежутков дня запрещено независимо от типов: время психолога одно.
3. Неизвестный тип в промежутке отвергается кодом `interval-type-unknown`.
4. Окна «Неделя» и «Особые часы» — отметки типов у каждого промежутка; в списках рядом с часами — названия типов.

## Критерии приёмки

- `SlotCalendarTest`: промежуток с перечнем даёт слоты только своим типам, промежуток без перечня — всем.
- `ScheduleIT`: промежуток для «Психотерапия очно» даёт её слоты и не даёт слотов консультации; неизвестный тип — 400.

## Ход работы

- 2026-10-01: столбцы `session_types UUID[]` у `work_interval` и `schedule_day_interval` (`rbot:004-interval-types`, `additive`, пустой массив по умолчанию: прежние промежутки — для всех типов). Компонент `IntervalTypes` в окнах недели и особых часов, подпись промежутка — `IntervalChip`.
- 2026-10-01: подпись промежутка с несколькими типами не помещалась в строку дня и наезжала на «Изменить» (замечание владельца) — подпись переносится, кнопка прижата вправо.
- 2026-10-01: типы промежутка показываются отдельными чипсами рядом с часами в неделе и в исключениях (замечание владельца): компонент `IntervalChip` вместо текстовой подписи.
- 2026-10-01: пустой перечень больше не означает «все типы» — тип обязателен, [RBOT-FEAT-008](../RBOT-FEAT-008-interval-types-required.md).
