# Текст о новой версии: «Пожалуйста, обновите страницу»

## Подтверждение

Поручение владельца от 2026-10-06: заменить текст на «Вышла новая версия. Пожалуйста, обновите страницу». Текст — `frontend/shared/update-available.ts`, общий для кабинета и приложения клиента.

## Последствия при сохранении текущего поведения

Текст длиннее нужного и расходится с желанием владельца.

## Требуется

1. Текст плашки — «Вышла новая версия. Пожалуйста, обновите страницу.»

## Критерии приёмки
