# Виджет времени без бесконечных запросов

## Проблема

На странице «Расписание» после загрузки без остановки летят запросы `openings?from=…&to=…`: сотни за секунды.

## Подтверждение

Снимок вкладки Network от владельца 2026-10-06: 458 запросов сразу после обновления страницы. Причина: эффект `OpeningsCard` вызывает загрузку, загрузка идёт через `Attempt.run`, а тот читает и меняет сигнал `busy`; эффект подписывается на `busy` и перезапускается после каждой загрузки. Тот же приём — в эффекте `SessionsPage` для `?at=` (RBOT-FEAT-020).

## Последствия при сохранении текущего поведения

Нагрузка на сервер и сеть, пока открыта страница расписания; на телефоне — расход батареи и трафика.

## Требуется

1. Загрузка в эффектах `OpeningsCard` и `SessionsPage` — в `untracked`: эффект зависит только от недели, версии расписания и `?at=`.

## Критерии приёмки

- После открытия «Расписания» — один запрос `openings` на неделю; смена недели — ещё один.

## Ход работы

- 2026-10-06: загрузка в обоих эффектах обёрнута в `untracked`.
- QA 2026-10-06: «Расписание» — один `GET openings`; «следующая неделя» — ещё один; два щелчка по времени — два `PUT`, без новых загрузок; «Записи» по `?at=` — один `GET sessions`, неделя 12–18 октября.
