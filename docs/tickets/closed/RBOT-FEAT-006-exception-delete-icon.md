# Удаление исключения кнопкой-иконкой

## Проблема

Кнопка «Вернуть обычные часы» в строке исключения длинная и переносится под дату и часы.

## Подтверждение

Замечание владельца от 2026-10-01: вместо «Вернуть обычные часы» — кнопка-иконка удаления.

## Последствия при сохранении текущего поведения

Строка исключения занимает две строки, список исключений растягивается.

## Требуется

Иконка корзины справа в строке исключения; подпись для экранного диктора «Удалить исключение: <дата>», подсказка при наведении.

## Критерии приёмки

- Строка исключения — одна строка на широком экране, иконка справа.
- Нажатие удаляет исключение, день возвращается к рабочей неделе.

## Ход работы

- 2026-10-01: `days-card.ts` — кнопка-иконка вместо текстовой, текст строки занимает оставшуюся ширину.
