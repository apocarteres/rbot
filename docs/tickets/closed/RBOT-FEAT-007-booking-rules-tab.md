# Вкладка «Правила записи» с пояснениями к полям

## Проблема

Вкладка называлась «Параметры», а поля — «Минимум до сессии», «Шаг слотов», «Перерыв после сессии» — без пояснений, что они меняют для клиента.

## Подтверждение

Замечание владельца от 2026-10-01: добавить короткое описание каждой настройки и переименовать вкладку.

## Последствия при сохранении текущего поведения

Психолог угадывает смысл полей; минимальный срок, который ограничивает и перенос с отменой, неочевиден.

## Требуется

Вкладка «Правила записи»; под каждым полем — одна строка пояснения, связанная с полем для экранного диктора. Тексты отказов и подсказка в строке состояния — тем же словом.

## Критерии приёмки

- Вкладка, ссылка «Заполните правила записи» и текст отказа `settings-incomplete` называют «Правила записи».
- У пяти полей есть пояснение, поля выровнены по верху.

## Ход работы

- 2026-10-01: `schedule.ts`, `settings-card.ts`, `preview-card.ts`, `frontend/shared/failures.ts`. Адрес вкладки прежний — `?tab=settings`.
