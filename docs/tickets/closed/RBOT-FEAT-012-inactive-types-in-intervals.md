# Выключенный тип сессии нельзя отметить у промежутка

## Проблема

В окне промежутков выключенные типы сессий отмечались наравне с включёнными, хотя записи на них нет.

## Подтверждение

Замечание владельца от 2026-10-01: если тип сессии выключен, галочка должна быть неактивной.

## Последствия при сохранении текущего поведения

Психолог отмечает выключенный тип и ждёт слотов, которых клиент не увидит.

## Требуется

У выключенного типа галочка неактивна, рядом — «выключен», подсказка ведёт на вкладку «Типы сессий». Если выключенный тип уже отмечен у промежутка, отметку можно снять.

## Критерии приёмки

- Выключенный неотмеченный тип отметить нельзя; отмеченный — можно снять.

## Ход работы

- 2026-10-01: `interval-types.ts`.
- 2026-10-01: пометка «выключен» красным, кнопка «Добавить промежуток» — «Добавить» (замечание владельца).
