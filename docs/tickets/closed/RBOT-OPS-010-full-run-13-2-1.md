# Полный прогон после смены версий компонентов ядром 13.2.1

## Проблема

Ядро 13.2.1 сменило версии компонентов платформы: com.fasterxml.jackson:jackson-bom закреплено ядром: 2.21.7; tools.jackson:jackson-bom закреплено ядром: 3.1.7. Набор verify это ловит лишь в той мере, в какой покрывает службу; сканер зависимостей и сценарии стенда в него могут не входить.

## Основание

Обязательство ядра `full-run-13-2-1`, требование `REQ-DEPS-010`, объявлено в версии ядра 13.2.1. Срок исполнения: 1 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. Полный набор verify на коммите с новой версией ядра (REQ-RELEASE-027).
2. Сканер зависимостей проекта на той же сборке — без новых находок либо с записанным решением по каждой.
3. Сценарии стенда, если проект их ведёт, — на службе с новой версией ядра.

## Критерии приёмки

- Задача называет, чем выполнен каждый шаг, и итог каждого.
- Проект без сканера или без стенда называет это в задаче, а не пропускает шаг молча.

## Ход работы

- 2026-10-01, ядро `13.7.0` (компоненты ядра `13.2.1` и новее: `jackson-bom` 2.21.7, `tools.jackson` 3.1.7 — закреплены BOM ядра):
  - полный `verify` — `mise run verify`, расписка записана наблюдённым прогоном: 17 модульных и 10 интеграционных тестов без отказов, правила ядра и документация без замечаний;
  - сканер зависимостей — `grype` 0.118.0 по `target/rbot-1.0.0.jar`: «No vulnerabilities found»; `npm audit --omit=dev` клиента: 0 уязвимостей;
  - сценарии стенда — QA (`scripts/deploy.sh --env qa`): health UP, `unknown` на обоих сайтах, вход администратора и психолога, баннер новой сборки, окно устаревшего API, страница «не найдено».
