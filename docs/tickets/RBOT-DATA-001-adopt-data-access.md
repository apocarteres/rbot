# Доступ к данным: без ORM, простой DAO, транзакция в прикладном слое

## Проблема

Слой доступа к данным содержит деловые решения: метод DAO выбирает между операторами, перечитывает записанное и выносит суждение об исходе, а граница транзакции объявлена там, где операцию вызвали, — у контроллера или у самого DAO. Деловое правило оказывается спрятанным в слое, где его не ищут, и исчезает из операции, вызванной другим путём.

## Основание

Обязательство ядра `data-access`, требование `REQ-DATA-ACCESS-002`, объявлено в версии ядра 1.11.0. Срок исполнения: 3 выпуск(ов) потребителя.

## Последствия при сохранении текущего поведения

Требование ядра действует, а проект ему не соответствует: расхождение обнаруживается не проверкой, а при следующем изменении в этой области.

## Требуется

1. Объектно-реляционное отображение не применяется: ни ORM, ни надстройки над ней, ни отображение по аннотациям сущностей.
2. Метод DAO выполняет один оператор к базе и отображает его результат: без ветвления между операторами, повторного чтения ради ответа и суждения об исходе сверх возвращённого оператором.
3. Несколько обращений к базе собраны в прикладном слое, и там же объявлена граница транзакции — ни в транспортном слое, ни в DAO, ни признаком, ни программным управлением.
4. Принадлежность класса прикладному слою объявлена проектом — пакетом, стереотипом или перечнем; проверка опирается на объявление, а не на суффикс имени.
5. К каталогу запросов обращается только слой доступа к данным.
6. Обобщённого DAO нет: ни базового класса с операциями над произвольным типом, ни отображения по описанию полей.
7. Проверки доступа к данным взяты готовыми из `platform-arch-rules` либо реализованы самостоятельно с тем же утверждением.

## Критерии приёмки

- `check` содержит проверку, отказывающую при обращении к каталогу запросов вне слоя доступа.
- `check` содержит проверку, отказывающую при объявлении транзакции вне прикладного слоя; наборы тестов из неё исключены.
- В проекте нет зависимостей от библиотек объектно-реляционного отображения.
- Перечень типов прикладного слоя объявлен и читается без разбора имён.
