# Документация receptionist-bot

Точка входа в требования, решения, задачи и выпуски сервиса записи к психологу: Telegram-бот, Mini App и кабинет психолога на общем ядре [platform](https://github.com/apocarteres/platform).

## Источники истины

1. Действующие [требования](REQUIREMENTS.md) задают обязательное поведение сервиса.
2. [Архитектурные решения](decisions/INDEX.md) объясняют выбор и альтернативы; после принятия их инварианты переносятся в требования.
3. [Задачи](tickets/INDEX.md) и [планы функций](tickets/features/INDEX.md) описывают порядок реализации и не являются источником требований.
4. Правила ведения документов, задач и выпусков доставляет пакет `@apocarteres/project-conventions`; здесь они не копируются.
